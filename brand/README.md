# Logo

The sun as a heart, over an olive branch that rolls like the sea. Colours from the Cyprus flag.

| File | Use |
| --- | --- |
| `logo-icon.svg` | App icon and social profile picture, white square |
| `logo-mark-transparent.svg` | The mark on its own, for print and partner material |
| `logo-small.svg` | Below about 48 px (browser tabs, the site header): heart and a plain wave, no leaves |

Colours: sun orange `#E8850C`, olive `#4E5B31`. On dark backgrounds: `#F29A2E` and `#9BAA6A`.

`make_logo.py` redraws the files.
